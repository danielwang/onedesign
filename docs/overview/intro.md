## What is it?

The N1 Design System is more than a component library. It defines how N1 should look, feel, behave, and communicate.

It brings together:

- **[Design principles](../foundations/design-principles.mdx)** — the thinking behind design decisions.
- **[Foundations](../foundations/visual-design-principles.md)** — colours, typography, spacing, icons, and design tokens.
- **[Components](../ui-components/example-component.md)** — reusable interface elements and usage guidelines.
- **Patterns** — consistent solutions to common interaction problems.
- **[Content guidelines](../foundations/voice-tones.md)** — voice, tone, terminology, and UX writing standards.
- **[AI resources](../ai-toolkit/ai-designing.md)** — structured guidance that helps AI tools follow the system.

The design guidance follows Google's DESIGN.md specification and works with Claude Code, Cursor, Codex, Gemini, ChatGPT, and other AI coding assistants.

## Why does it exist?

As N1 grows, consistency becomes harder to maintain. The design system helps teams build consistently, move faster, improve quality, and scale with AI.

> Whether the work is done by people, AI, or both.

## Who is it for?

- ![](/img/personas/peter-professor.svg) **Designers** make informed design decisions and create consistent experiences.
- ![](/img/personas/dora-developer.svg) **Developers** build interfaces using shared components, tokens, and patterns.
- ![](/img/personas/cyrus-cio.svg) **Product managers** understand the design principles and align product decisions.
- ![](/img/personas/molly-moderator.svg) **Content designers** write clear, consistent, and helpful UI language.
- ![](/img/personas/sarah-student.svg) **Marketers** create on-brand experiences across campaigns and channels.
- ![](/img/personas/robot-ai.png) **AI assistants and coding agents** generate and review interfaces using N1 standards and guidelines.

## How to use it

**For people:** Explore the documentation based on what you are working on. Start with the [design principles](../foundations/design-principles.mdx), then use the relevant [foundations](../foundations/visual-design-principles.md) and [components](../ui-components/example-component.md) as you design or build.

**For AI tools:** Use the [AI resources](../ai-toolkit/ai-designing.md) and machine-readable documentation to give your assistant the right design context.
